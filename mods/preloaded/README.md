# Built-in Tomba 2 mods

These packages are copied beside the runtime and appear on the launcher's Mods
page. They contain metadata only; trusted native activation callbacks are
compiled into Tomba2Recomp.

All three enhancements are disabled by default. The target hash is the SHA-256 of
the SCUS-94454 MODE2/2352 data-track BIN used by the mod loader for identity.
